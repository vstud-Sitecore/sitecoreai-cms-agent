# Edit Sitecore content

Use the [shared Draft workflow](../../references/draft-workflow.md#writing-and-verifying-a-sitecore-draft) and [content field rules](../../references/content-fields.md) for all fields. First resolve the item or component datasource, site, language and exact field. Reuse the user's supplied values. For an image swap, a public delivery URL is sufficient asset input.

Apply only the requested edit. A targeted change needs no new mapping, page naming, folder setup, or full page intake. For an event schedule or registration change, use the event builder's [existing-page steps](../sitecore-agentic-event-page/SKILL.md#edit-an-existing-event) to check the affected settings together. Verify only the changed content and its dependencies, then report the edited version and preview result.
